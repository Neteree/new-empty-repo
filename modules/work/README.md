# Past work

A grid of past projects (a builder's renovations, a web designer's sites), each with a picture, what kind of job it was and one line about it. Data in `work.json`; pictures in `src/assets/photos/`. A client JSON key `"work": { "items": [...] }` fills it in. `demo: true` adds a "Demo" tag (anything that isn't a real client's work, shown with permission, must have it). `section.frame: "browser"` draws screenshots in a browser window.
